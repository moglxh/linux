# Linux

This repository contains my Linux study notes, experiments, scripts, labs, and research.

The primary goal is to build a practical understanding of Linux from the user space down to the kernel. Most material here is focused on operating system behavior, troubleshooting, privilege boundaries, process execution, filesystems, networking, and kernel-related topics.

## Areas Covered

* Linux Fundamentals
* Shell Usage
* Process Management
* Users and Permissions
* Filesystems
* Networking
* Systemd
* Bash Scripting
* Linux Privilege Escalation Research
* Kernel Internals
* Linux Security Concepts

This repository serves as a long-term knowledge base and working notebook. Rather than storing isolated course notes, the focus is on documenting observations, experiments, and practical understanding gained while working with Linux systems.
